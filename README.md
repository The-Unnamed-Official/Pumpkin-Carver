# Pumpkin Carver

A simple installable pumpkin carving app. Draw on the pumpkin, undo, or start over. English, Norwegian and Japanese, with language and designs saved automatically on your device.

No dependencies or build step. Serve these files from an HTTPS static host. On mobile, use Install app / Add to Home Screen.

Original pumpkin image and carving implementation: rollingsimulator.com (The Unnamed).
